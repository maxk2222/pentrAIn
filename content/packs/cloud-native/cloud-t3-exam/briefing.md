# Exam: Platform Assurance

> **Track**: Cloud Native · **Tier**: 3 exam · **Estimated time**: ~45 min

## Scenario

The cloud platform board has assembled evidence from workload identity,
metadata access and production reconciliation. Deliver one assessment that
prioritizes risks across the full control plane.

## Objectives

1. Correlate the evidence and define immediate and permanent controls.
2. Submit `platform-assurance-report`.

## Environment

- **Kali**: evidence under `/opt/pentrain-audit/cloud/`
- **Report**: `/tmp/pentrain-audit-reports/platform-assurance.md`

## Rules of engagement

- Exam mode: no hints or walkthrough are provided.
- Use only synthetic evidence; do not contact cloud services or apply manifests.
- Include evidence, impact, remediation and safe verification.
