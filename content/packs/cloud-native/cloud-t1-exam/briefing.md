# Exam: Production Boundary

> **Track**: Cloud Native · **Tier**: 1 exam · **Estimated time**: ~35 min

## Scenario

The cloud platform review board has supplied a Kubernetes permission bundle
and a release-workflow bundle. Assess whether the current design is ready for
production and submit a prioritized remediation plan.

## Objectives

1. Assess workload authorization and release provenance.
2. Submit the report as `cloud-exam-report`.

## Environment

- **Kali**: evidence under `/opt/pentrain-audit/cloud/`
- **Report**: `/tmp/pentrain-audit-reports/cloud-exam.md`

## Rules of engagement

- Exam mode: no hints or walkthrough are provided.
- Use only the local synthetic evidence and do not deploy its configuration.
- Include impact, evidence, remediation and a testable verification step.
