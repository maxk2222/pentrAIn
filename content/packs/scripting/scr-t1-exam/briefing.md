# Exam: Report Generator

**Tier-1 capstone — Scripting & Automation.** Everything from this tier,
one script: `audit01` exposes three data sources — its SSH auth log, an
anonymous-FTP asset inventory, and a JSON status endpoint. The SOC wants a
single machine-readable report, generated by one script.

**Deliverables**

1. `/root/report.sh` — runs unattended and produces the report.
2. `/root/report.txt` — exactly three lines in this exact format:

   ```
   SERVICES=<service names, comma-separated, from the status endpoint>
   ATTACKER=<the single source IP with the most failed logins>
   ASSETS=<hostnames from the FTP inventory, comma-separated>
   ```

The grader checks the report literally — format counts as much as content.

**This is an exam.** Solve every tier-1 scripting quest first; no hints
from the coach until you've earned them here.

Difficulty: easy · Track: Scripting & Automation
