# Exam: Helio Support

> **Track**: AI Security · **Tier**: 1 exam · **Estimated time**: ~30 min

## Scenario

Helio is preparing a customer-support assistant for a wider rollout. An
incident review found unexpected cross-business-unit retrieval and a tool
action that lacked a clear authorization record. Deliver a concise security
assessment from the local evidence bundle.

## Objectives

1. Identify the data, identity and action-control weaknesses.
2. Submit a prioritized report as `ai-exam-report`.

## Environment

- **Kali**: local evidence at `/opt/pentrain-audit/ai/tool-boundary-exam.md`
- **Report**: `/tmp/pentrain-audit-reports/helio-assessment.md`

## Rules of engagement

- Exam mode: no hints or walkthrough are provided.
- Use only the supplied synthetic evidence; do not attempt actions against a live agent.
- Include a finding, evidence, impact, remediation and verification for each issue.
